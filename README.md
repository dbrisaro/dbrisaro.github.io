# danielarisaro.ar

Personal website of Daniela Belén Risaro, climate data scientist and oceanographer based in Buenos Aires. PhD in Atmospheric and Oceanic Sciences, specializing in data science and remote sensing for climate risk assessment.

Built with [Jekyll](https://jekyllrb.com/) and the [Academic Pages](https://github.com/academicpages/academicpages.github.io) theme (Minimal Mistakes), published via GitHub Pages at [danielarisaro.ar](https://danielarisaro.ar).

## Sections

- **About**: bio, research interests, recent news
- **Publications**: journal articles, theses, policy reports, and outreach pieces
- **Portfolio**: data science and climate projects
- **CV**: full academic and professional CV
- **Teaching**: courses taught at UBA and UTDT
- **Outreach**: science communication and public engagement
- **Blog**: longer-form posts on climate, data, and methods

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

The site uses Ruby 3.3 and Jekyll 4.4. Sass deprecation warnings during build are expected and harmless; they come from the upstream theme.

## Structure

```
_pages/        # Main site pages
_publications/ # Publication entries (.md per item)
_portfolio/    # Portfolio project entries (.md per item)
_posts/        # Blog posts
_teaching/     # Teaching entries
_data/         # Navigation (navigation.yml) and UI config
assets/        # CSS, JS, images
files/         # Downloadable files (PDFs, datasets)
```

## Deployment

Pushes to `master` trigger an automatic build on GitHub Pages. No CI configuration needed. The sitemap at `/sitemap.xml` is auto-generated by the `jekyll-sitemap` plugin.
